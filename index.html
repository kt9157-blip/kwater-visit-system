K-water 방문 사전신청 통합 시스템

부서 신청 · 관리자 승인 · 초소 모니터링 · 출입 확인

통합 단일 HTML · LocalStorage 기반

방문 신청부터 현장 확인까지 한 화면에서 관리합니다.

관리자는 계정 승인과 방문 승인, 부서 사용자는 방문신청, 정문초소·안내데스크·세종관·후문은 모니터링 및 입·퇴문 확인 용도로 사용할 수 있습니다.

로그인

관리자 또는 승인된 부서 사용자 계정으로 접속합니다.

초기 관리자 계정
admin01 / kwater1234 / 비상계획처
admin02 / kwater1234 / 정보보안처
admin03 / kwater1234 / 시설관리부
실제 사용 전에는 HTML 하단 스크립트의 SEED_ADMINS 값을 기관 내부 기준에 맞게 변경하세요.

모니터링 전용 접속

정문초소, 1ㆍ3층 안내데스크, 세종관, 후문 등에서 신청·승인 현황을 확인하고 입문/퇴문 처리합니다.

팝업 알림은 이 파일이 같은 브라우저 또는 같은 웹주소에서 열려 있을 때 동작합니다. 여러 PC 실시간 공유는 서버/DB 연동이 필요합니다.

부서 사용자 계정 신청

각 부서별 1~2명 신청을 기준으로 하며, 관리자가 승인해야 방문신청 기능을 사용할 수 있습니다.

최근 방문신청

가장 최근 등록된 방문신청입니다.

대기 중 계정 신청

관리자 승인이 필요한 부서 사용자 계정입니다.

방문 사전신청

방문자 정보와 방문 목적을 입력하면 관리자·모니터링 화면에 자동 팝업이 표시됩니다.

내 신청 현황

본인이 등록한 방문 신청의 승인 상태를 확인합니다.

방문 신청 승인 관리

방문신청을 검토하고 승인/반려 처리합니다. 관리자 메모는 초소·안내데스크에서도 확인됩니다.

계정 승인 대기

부서 사용자 신청을 승인 또는 반려합니다. 부서별 승인 사용자는 최대 2명으로 제한됩니다.

등록 계정 현황

관리자 및 승인/대기/반려된 부서 사용자 계정 목록입니다.

모니터링 / 출입 확인

정문초소, 1ㆍ3층 안내데스크, 세종관, 후문 등 현장 확인용 화면입니다.

데이터 관리

단일 HTML·브라우저 저장소 기반으로 동작합니다. 백업 파일을 내려받아 관리할 수 있습니다.

방문신청은 기본 7일 경과 시 정리 대상입니다. 기간은 스크립트의 RETENTION_DAYS 값으로 조정할 수 있습니다.

운영 기준

권장 운영
① 관리자: 2~3개 부서 담당자 계정으로 제한
② 부서 사용자: 부서별 1~2명 신청 후 관리자 승인
③ 모니터링: 정문초소, 1ㆍ3층 안내데스크, 세종관, 후문 등 전용 화면 사용
④ 신청 발생 시: 관리자/모니터링 화면에 팝업·토스트·브라우저 알림 표시
